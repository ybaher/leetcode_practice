# Algorithms Starter Path

This folder is for learning algorithms before jumping into full LeetCode.

The goal is not to memorize solutions. The goal is to learn how to turn a plain-English idea into code.

## How to Practice

For each problem:

1. Say the input and output out loud.
2. Try a tiny example by hand.
3. Write the simplest code you can.
4. Run the tests.
5. Only then think about making it faster.

## Level 1: Loops and Conditions

These problems teach you how to scan through data one item at a time.

1. Count how many numbers are positive.
2. Find the biggest number in a list.
3. Count how many times a word appears.
4. Return all even numbers.
5. Check if a string has the letter "a".

## Level 2: Building Results

These teach you how to create a new answer while looping.

1. Double every number in a list.
2. Reverse a string.
3. Remove all vowels from a string.
4. Keep only words longer than 3 letters.
5. Add up all numbers in a list.

## Level 3: Common Algorithm Patterns

These are the patterns LeetCode uses constantly, but in easier form.

1. Two Sum, easy version: find two numbers that add to a target.
2. First duplicate: return the first repeated value.
3. Count characters in a string.
4. Find the most common word.
5. Check if a word is a palindrome.

Start with `starter_practice.py`.
